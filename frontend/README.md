# Business Management Dashboard

A small MVP with login, a dashboard showing customer statistics, and customer management.

## Technologies used
- React (Vite): frontend
- Node.js and Express: backend API
- SQLite: database
- bcryptjs and JWT: password hashing and login tokens
- Insomnia: API testing
- Git and GitHub: version control

## Database
users: id, username, password
customers: id, name, email, phone, status, created_at

## How to run
Backend: go into the backend folder, run npm install, then node server.js
Frontend: go into the frontend folder, run npm install, then npm run dev
Login: admin / password123
